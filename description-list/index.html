Description List

Label and value rows on a real <dl>: the facts of a case study, a spec sheet, a profile's details. Terms in the label role (muted), values in body ink. Three layouts — stacked, terms beside their values, or groups side by side — plus a large value size and rules above and below. Pure CSS. For a list of actions, use List; for numbers with trends, use Stat.

a11y (built in): it stays a native <dl>, so screen readers announce terms and their descriptions as pairs; a <div> around a term and its values is valid HTML and is how the grid layout groups them. No roles are added.

Usage: <dl class="lb-description-list"> with <dt class="lb-description-list__term"> and <dd class="lb-description-list__details"> (several dd per term are fine). Layouts: default (stacked), --inline (term column, width --lb-description-list-term; stacks on phones), --grid (wrap each pair in a <div>; column floor --lb-description-list-min). --large sets values in heading-m, --ruled adds a rule above and below.
