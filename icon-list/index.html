Icon List

A short content list where each line starts with an icon: the principles a delivery meets, what a plan includes, pros and cons. The icon sits on the item's first line at the text's own size and takes the text's ink unless a status colours it. Sizes follow the type scale. Pure CSS. Not to be confused with List, the interactive menu list.

a11y (built in): a native <ul> keeps the list semantics and item count. Icons are decorative (aria-hidden="true"): when an icon carries meaning, as in a pros and cons list, say it in the text too or add a visually hidden word (.lb-visually-hidden), because colour and shape alone are not announced.

Usage: <ul class="lb-icon-list"> of <li class="lb-icon-list__item">, each starting with <span class="lb-icon-list__icon" data-lb-icon="check" aria-hidden="true"> then the text. Icon colour: __icon--success, --warning, --danger, --muted (default: the text ink). Sizes: default body-m, .lb-icon-list--large body-l, --xlarge heading-xl.
