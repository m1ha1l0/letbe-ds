Animation

Motion tokens — durations (0–500ms for UI, 700ms for expressive motion) and easing curves. L2 aliases give semantic names like dur-fast (100ms, state changes), dur-normal (150ms, menus/tooltips), dur-gentle (200ms, transitions), ease-ui (standard UI), and ease-bounce (playful spring). The expressive tier — dur-expressive (700ms), ease-expressive, ease-expressive-in and ease-expressive-out (exits, on the shorter dur-slow) — is for large surfaces and content arriving and leaving (full-screen menu and modal, scroll reveal, media zoom), never for UI feedback. dur-stagger (50ms) is the gap between items in a cascade. Components that animate drop their motion individually under prefers-reduced-motion: reduce — there is no global reset.

a11y (built in): under prefers-reduced-motion: reduce the previews below freeze and a visible notice appears above them — the token values still resolve, only the motion stops. Each row carries a real <button aria-label="Play preview">, so a preview is keyboard-triggerable rather than hover-only, and continuous looping is opt-in behind a role=switch toggle that starts off. Components with ambient or transform motion drop it under the same query — the badge pulse and the interactive-card lift, among others.

Motion control — data-lb-motion

Every letbe-ds motion can be switched off where you choose. Put data-lb-motion="off" on <html> for the whole site, on a section, or on one component, and everything inside becomes instant: transitions, the entry and exit of overlays, the scroll reveal and count-up, the lightbox glide, smooth scrolls. Overlays still open, close and return focus exactly as before. Overlays the script moves under <body> (lightbox, colour picker, calendar popover) take the mode of the element that opened them. Repeating indicators follow the reduced-motion rules: the spinner keeps turning slowly, the shimmer, pulse and streaming caret stop. Useful for screenshot tests, a calm page, or a part of a page that should stay still.

The user's setting always wins: under prefers-reduced-motion: reduce letbe-ds drops its movement on its own, and nothing a site sets turns it back on. Retiming is a token change: re-declare --lb-animation-dur-* and --lb-animation-ease-* in your theme layer. Your own scripts can ask the same question: LB.motion(el) returns 'off', 'reduce' or 'full' for the motion at el.

<html data-lb-motion="off">                       <!-- the whole site -->
<section data-lb-motion="off">                    <!-- one part of a page -->
<div class="lb-accordion" data-lb-motion="off">  <!-- one component -->

Your own overlay motion — data-lb-motion="custom": on an overlay, or around it, the built-in entry and exit of modals, sheets, drawers, menus and lists, popovers, toasts and the command palette stop playing, and nothing else changes. The script still adds the leaving class when the overlay closes and waits for whatever animation you put on it, then hides the overlay and returns focus. So your own curtain, wipe or rise needs no override of letbe-ds CSS: animate the element when it appears, and its leaving class when it goes.

/* <div class="lb-modal-backdrop contact" data-lb-modal data-lb-motion="custom"> */
.contact { animation: curtain-in var(--lb-animation-dur-expressive) var(--lb-animation-ease-expressive); }
.contact.lb-modal-backdrop--leaving { animation: curtain-out var(--lb-animation-dur-slow) var(--lb-animation-ease-expressive-out) forwards; }

The leaving classes: .lb-modal-backdrop--leaving (modal, lightbox), .lb-sheet-root--leaving, .lb-header--drawer-leaving (on the header, for both drawers), .lb-dropdown-list--leaving (Select, Multi-Select and Dropdown lists), .lb-toast--leaving. Under prefers-reduced-motion keep your own motion small or skip it, as letbe-ds does.

Scroll reveal — data-lb-reveal

Add data-lb-reveal to a block and it rises a little and fades in the first time it scrolls into view; blocks arriving together come in one after another (a short stagger, at most 6 steps). data-lb-count-up on a number (a Stat value) counts every number in its text up from 0 when it comes into view, while assistive tech reads the final value. Each number keeps its written format as it counts: thousands marks and decimals follow the page's lang (2,000 and 4.5 in English, 2 000 and 4,5 in Swedish), a year (1900–2099 written as 4 plain digits) stays as written, and so does anything inside data-lb-count-up="off". A number inside a sentence holds its final width, so the line never moves. Core runtime, no setup.

Accessible by construction: nothing is hidden unless motion is welcome (prefers-reduced-motion: no-preference) and the browser has IntersectionObserver; only opacity and translate move (no layout shift, the element keeps its own transitions); hidden blocks stay in the page for screen readers and find-in-page; focus that lands in a block shows it at once; print shows everything. lb.js sets html.lb-reveal-on when it starts, so a block already on screen at load may show for a frame before it rises — to avoid that, set the class in the <head> with a fallback that takes it back if lb.js never arrives:

Timing of its own: the reveal runs on the expressive tokens it shares with the full-screen menu and modal. To give it a different pace without slowing those, set --lb-reveal-dur, --lb-reveal-ease and --lb-reveal-step (the gap between blocks arriving together) on :root, a section or one block. Each falls back to the tokens, takes a plain time or a calc() on the duration tokens, and data-lb-motion="off" still wins over them. The count-up takes --lb-count-up-dur (default 1100ms) the same way, the card media zoom --lb-card-zoom-dur and -ease, and the accordion has the same kind of settings (--lb-accordion-dur, -dur-close, -ease); everything else follows the tokens.

:root {
  --lb-reveal-dur: 1000ms;
  --lb-reveal-ease: var(--lb-ease-standard);
  --lb-reveal-step: 110ms;
}
<script>
  if (matchMedia('(prefers-reduced-motion: no-preference)').matches && 'IntersectionObserver' in window) {
    document.documentElement.classList.add('lb-reveal-on');
    setTimeout(function () { if (!window.LB) document.documentElement.classList.remove('lb-reveal-on'); }, 3000);
  }
</script>
