Kbd

A keyboard key, for shortcut hints in menus, search fields, help lists and command palettes: a mono keycap on the strong neutral fill. Pure CSS on the native <kbd> element.

a11y (built in): <kbd> tells assistive tech the text is keyboard input. Write one <kbd> per key so a chord reads as separate keys. When a hint repeats a control's visible label, hide the hint (aria-hidden="true") and put the shortcut on the control with aria-keyshortcuts instead. Show the platform's modifier: ⌘ on Apple devices, Ctrl elsewhere.

Usage: <kbd class="lb-kbd">⌘</kbd><kbd class="lb-kbd">K</kbd>. Adjacent keys keep a hairline gap. Inside a list row, the trailing .lb-list__hint slot holds them; inside the dark tooltip, use .lb-tooltip__kbd.
