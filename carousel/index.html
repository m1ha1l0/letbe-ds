Carousel

A row that pages one item per click — LB.Carousel, core runtime. It runs on native scroll-snap, so touch swipes and trackpads simply scroll it; the arrows step one item. Optional endless loop. A row that already fits stays still and hides its controls. For a plain sideways overflow without paging, use Scroll Area.

a11y (built in): the root becomes role="region" with aria-roledescription="carousel" (name it with aria-label), each item a role="group" slide labelled "n of N", and a polite status announces the position after every step. ←/→ step while focus is inside. Loop clones are inert and aria-hidden, so links and buttons exist once for keyboards and screen readers. Without loop the arrows disable at the ends. Reduced motion: steps jump instead of gliding.

Usage: <section class="lb-carousel" data-lb-carousel aria-label="…"> holding .lb-carousel__viewport > .lb-carousel__track > items and a .lb-carousel__controls row with [data-lb-carousel-prev] / [data-lb-carousel-next] icon buttons (and an optional visible .lb-carousel__status). Add data-lb-carousel-loop for the endless row, .lb-carousel--cards for a card row where the next card peeks in. Sizing: --lb-carousel-item (item width) and --lb-carousel-gap. Instance at el._lbCarousel: next(), prev(), goTo(i), refresh() (after changing items); emits lb-carousel-change { index, count }.
